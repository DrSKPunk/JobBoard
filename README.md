# *Джоб-борд - это сайт для поиска работы и сотрудников*

# *Описание предметной области*

# Предметной областью разрабатываемой базы данных является сайт по-иска работы. Система предназначена для взаимодействия соискателей и рабо-тодателей, размещения вакансий, создания резюме и отправки откликов на ин-тересующие вакансии.

# Пользователь может зарегистрироваться в системе в качестве соискате-ля или работодателя. Соискатель размещает резюме с информацией о желае-мой должности, образовании, опыте работы и профессиональных навыках. Ра-ботодатель представляет компанию и размещает на сайте информацию об от-крытых вакансиях.

# Основным объектом поиска являются вакансии. Для каждой вакансии указывается название, описание, размер заработной платы, город  и дата пуб-ликации. Соискатель может выбрать подходящую вакансию и отправить на неё отклик.

# *Основные бизнес-процессы системы*

# Бизнес-процесс регистрации пользователя начинается с создания учёт-ной записи. Пользователь указывает основные персональные данные и выбира-ет роль в системе. После регистрации пользователь получает возможность пользоваться функциями, соответствующими его роли.

# Для соискателя основным процессом является поиск подходящей рабо-ты. Соискатель просматривает опубликованные вакансии, использует сведения о должности, городе, заработной плате для выбора подходящего предложения. После выбора вакансии соискатель может создать или выбрать своё резюме и отправить отклик.

# Другим важным процессом является создание и редактирование резю-ме. В резюме указывается желаемая должность, образование, опыт работы, информация о соискателе и профессиональные навыки. Соискатель может об-новлять информацию о себе, чтобы она соответствовала актуальному профес-сиональному опыту.

# Для работодателя основным бизнес-процессом является размещение вакансии. Работодатель указывает название должности, описание работы, тре-бования, размер заработной платы и город. После публикации вакансия стано-вится доступной соискателям.

# Следующий процесс обработка откликов. Работодатель получает ин-формацию о соискателях, откликнувшихся на вакансию, просматривает их ре-зюме и изменяет статус отклика. В результате работодатель может продолжить взаимодействие с подходящим кандидатом или отказать ему
